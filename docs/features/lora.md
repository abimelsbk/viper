# LoRa

Long-range, low-power text chat between Viper devices, with no Wi-Fi or phone network involved.

**Hardware:** an **SX1276** or **SX1262** LoRa module (choose the chip when prompted), wired to the pins under **Config → System Config → Advanced → Set Device pins → LoRa Pins**. Boards like the T-LoRa Pager have one built in.

| Entry | What it does |
|---|---|
| **Chat** | Send and receive short messages with any other Viper on the same frequency |
| **Change username** | The name shown next to your messages |
| **Change Frequency** | Pick the band. Use the legal one for your region, e.g. 433, 868 (EU/India) or 915 MHz (Americas) |

Everyone in the chat must use the same frequency. Messages are not encrypted.
