# NRF24

Uses an **nRF24L01+** 2.4 GHz module on the SPI pins set under **NRF24 → Config pins**. On sticks and Cardputer a combined CC1101 + NRF24 board is common. See [Supported devices](../hardware/devices.md).

| Entry | What it does |
|---|---|
| **Information** | Check that the module answers, and show its settings |
| **Spectrum** | Live activity across the 2.4 GHz channels: Wi-Fi, Bluetooth, drones, wireless peripherals |
| **MouseJack** 🧪 | Test older unencrypted wireless mice and keyboard dongles for keystroke-injection weaknesses. Use only with your own peripherals |
| **NRF Jammer** 🧪 | Transmit on 2.4 GHz channels. Illegal outside a shielded test setup in most countries |
| **Config pins** | Set CE / CSN and the SPI bus for the module |
