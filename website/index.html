04 Install

1

Web Flasher

Chrome or Edge on desktop. Plug your device in over USB, pick the board, click install.

Open flasher
2

esptool

Download Viper-<board>.bin from Releases and write it at offset 0:

esptool.py --port COM5 write_flash 0x0 Viper-m5stack-cores3.bin
3

Build it yourself

Clone the repo, install PlatformIO, then:

pio run -e m5stack-cores3 -t upload

05 FAQ

I used Bruce before. Do I lose my settings?

No. On first boot Viper renames /bruce.conf and /brucePins.conf to the Viper names and reads saved Bruce capture files. Move your SD folders from /BruceRF, /BruceIR and so on to /ViperRF, /ViperIR and so on to keep using them.

How do I skip the boot animation?

Press any key. To use your own splash, put boot.jpg or boot.gif on the SD card root.

Can I use it on a bare ESP32-WROOM?

Yes. Use the esp-wroom32-ili9341 or esp-wroom32-st7789 build with a matching SPI display, or the CYD-2432S028 build for the Cheap Yellow Display.

Is this legal to use?

Viper is a research and education tool. Only test networks, radios and devices you own or have written permission to assess. You are responsible for following the laws where you live.
